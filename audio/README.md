# Аудиокнига

Публикационный каталог. Пустой manifest.json означает, что плееры и кнопки скачивания не показываются. Не добавлять пробные записи в рабочий каталог.

После полной проверки записи загрузить MP3 и добавить запись в chapters, ключ — существующее имя страницы, например chapter-1.html. Поля: approved: true, title: точный текст h1 опубликованной страницы, src: audio/chapter-01.mp3, download: audio/chapter-01.mp3. Это описание структуры, а не готовая запись манифеста.

Плеер появляется только после successful loadedmetadata и положительной конечной длительности. Ошибка файла удаляет блок. Положение сохраняется локально на устройстве; автозапуск отсутствует. Загрузка и скачивание по умолчанию с того же сайта. Для внешнего хранилища сначала проверить HTTPS, HTTP Range, Content-Type audio/mpeg, заголовок Content-Disposition и загрузку на iOS/Android; текущая версия требует одноимённую ссылку скачивания того же origin.

Каждый MP3 хранить меньше 100 MB. Целевой битрейт речи — 96 kbit/s, моно; сохранять оригинальный WAV отдельно вне репозитория. При прогнозируемом трафике выше 70 GB/месяц пересмотреть хранение до приближения к мягкому пределу Pages 100 GB. MP4 и рабочие WAV на Pages не размещать. Не подключать платные сервисы без разрешения.

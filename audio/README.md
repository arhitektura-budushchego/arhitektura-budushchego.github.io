# Русскоязычная аудиокнига

Введение и главы 1–14 — оригинальные MP3, переданные владельцем. Байты записей не изменяются. Сопоставление номеров, точные заголовки опубликованных страниц, длительности, размеры и SHA-256 — в manifest.json (version 2). Контрольные суммы: originals.sha256.

На audiobook.html используется один HTML5 audio: кнопка начала, выбор любой главы, предыдущая/следующая, пауза/продолжение, автоматическое продвижение до конца главы 14. На каждой странице главы тот же компонент создаёт один компактный плеер. Позиция хранится локально в браузере, звук при открытии страницы не запускается. При запрете следующего запуска браузером предлагается кнопка продолжения. Каждая запись скачивается отдельно по прямой ссылке.

Временная передача крупнейшего файла может использовать .audio-staging и одноразовую сборку на ветке feature/russian-audiobook: это соединение исходных байтов с проверкой SHA-256, без перекодирования, обрезки или изменения аудио. До приёмки все части должны быть удалены, а audio/chapter-7.mp3 должен существовать как обычный полный оригинал. На действующий сайт сборка не влияет.

# Русскоязычная аудиокнига: отчёт перед публикацией

**Подготовлено в отдельной ветке `feature/russian-audiobook`. На действующий сайт не опубликовано.** Основой взята текущая main `7b3e47f42ae3609fb27b09ea3ef74bb64b7dd1d7`, уже содержащая GoatCounter и свободное распространение книги. Слияние — только после окончательного утверждения владельцем.

## Оригиналы и названия

Получены все 15 MP3 владельца: введение.mp3 и 1.mp3–14.mp3. После копирования проверены ожидаемые размеры, а после переноса в GitHub — SHA-256 и Git blob SHA. Переданные аудиобайты не перекодировались, не обрезались и не переозвучивались. Меняются только серверные имена: `введение.mp3 → audio/introduction.mp3`, `N.mp3 → audio/chapter-N.mp3`.

Объём **85 610 019 байт** (85,61 МБ / 81,64 МиБ), общая длительность **2:58:20,8**. Самый большой оригинал — глава 7: 13 411 821 байт, ниже ограничения GitHub в 100 МиБ на файл. Суммарный объём опубликованных файлов около 90 МБ, существенно ниже 1 ГБ.

Названия всех 15 записей точно сверены с действующим оглавлением `https://arhitektura-budushchego.github.io/read.html`, а не с прежними планами. В частности, последняя запись соответствует **главе 14 «Будущее начинается с тебя»**.

Все файлы полностью декодированы FFmpeg без ошибок. Для содержательной сверки локально распознаны первые 25 секунд каждой записи и последние 45 секунд главы 14: начала совпадают с соответствующими текстами, последняя запись завершается призывом начать с себя и фразой «Будущее начинается с тебя». Это проверка соответствия записей главам, не сплошная редакторская сверка всех трёх часов речи; отдельные ошибки автоматического распознавания не трактовались как ошибки оригинала. Оригиналы при проверке не изменялись.

## Функции

- В основном меню добавлена ссылка **«Слушать аудиокнигу»** рядом с чтением и скачиванием.
- Страница `audiobook.html` содержит введение и 14 глав в правильном порядке, точные названия, длительности, ссылки на чтение и скачивание каждого оригинального MP3.
- На странице — один HTML5-аудиоплеер, без рекламы и сторонних сервисов воспроизведения. Выбор главы меняет источник этого плеера, не создаёт новые экземпляры.
- **«Слушать с начала»** запускает введение; затем автоматически следуют главы 1–14. После главы 14 воспроизведение останавливается.
- Доступны **«Предыдущая глава»**, **«Следующая глава»**, **«Пауза»**, **«Продолжить»**, выбор любой записи из списка, штатная перемотка, текущая позиция и длительность.
- Глава и позиция сохраняются только в localStorage браузера. При повторном открытии звук не запускается: продолжение требует нажатия кнопки.
- Если браузер отклоняет запуск следующего файла с NotAllowedError, выводится понятное сообщение и доступна кнопка **«Продолжить»**. Ошибки загрузки не скрываются и не вызывают молчаливый пропуск главы.
- На каждой странице главы и введения — один компактный экземпляр того же плеера с соответствующей записью. Чтение не меняется. Для поддерживающих BroadcastChannel браузеров запуск звука в другой вкладке ставит прежний плеер на паузу.

## Проверки

**Пройдено 186 браузерных проверок.** Испытания выполнялись на локальной копии файлов ветки с настоящими MP3 и поддержкой HTTP Range. GoatCounter в тестовом браузере отключён, технические прослушивания не увеличивали статистику сайта.

- Проверены воспроизведение и перемотка **всех 15 реальных MP3** в Chromium на ширине компьютера и в мобильной эмуляции.
- Проверена вся цепочка: введение → главы 1–14; переходы проверялись реальными событиями ended после перемотки к концу каждой записи. Полного трёхчасового ожидания не требовалось.
- Проверены остановка после главы 14, начало с произвольной главы, переходы назад/вперёд, пауза и продолжение.
- Проверено восстановление главы 7 и позиции 37 секунд после перезагрузки без автоматического звука.
- Проверена обработка искусственно смоделированного запрета запуска следующего файла и успешное продолжение после нажатия кнопки.
- Для всех 15 ссылок скачивания проверяются байты против SHA-256 оригиналов; для главы 14 дополнительно проверено штатное браузерное скачивание.
- Проверены светлая/тёмная темы и отсутствие горизонтального переполнения на ширинах 1280 и 390 px. Снимки ниже.
- Проверено точное сохранение текста всех 15 книжных страниц, настроек чтения, исходных файлов книги, style.css, условий распространения и файлов GoatCounter.
- JavaScript проходит синтаксическую проверку. Ошибок JavaScript или загрузки MP3 в успешных сценариях не обнаружено.

Мобильная проверка — **эмуляция Chromium**, а не физический iPhone/Safari. Автопродолжение в реальном Safari может зависеть от его политики и режима фоновой работы; поэтому кнопка продолжения остаётся обязательной частью решения. На сайте нет autoplay при первом открытии.

## GitHub Pages и нагрузка

Прямое размещение оригиналов в GitHub Pages подходит по объёму. По документации: опубликованный сайт до 1 ГБ, мягкий лимит трафика около 100 ГБ в месяц. При тысяче полных скачиваний/прослушиваний аудио получится примерно 85,6 ГБ без учёта повторных загрузок и другого трафика; большая аудитория может потребовать отдельного решения. Фактическая будущая аудитория неизвестна, бесконечный бесплатный трафик не обещается. Платное хранение, Git LFS и внешние аудиосервисы не подключались.

Источник: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits и https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github .

При переносе самого большого файла лимит размера запроса инструмента оказался ниже лимита GitHub. Одноразовая задача бесплатного стандартного GitHub Actions соединила транспортные части обратно в исходный MP3 и сверила SHA-256 всех 15 файлов. Задача завершилась успешно: https://github.com/arhitektura-budushchego/arhitektura-budushchego.github.io/actions/runs/40008798693 . В итоговой ветке должны оставаться только полные MP3, без временных частей и вспомогательного workflow. Сайт и плеер не используют ни сборку, ни фоновые задачи при прослушивании.

## Команды проверки

- `python3 tests/integrity.py`
- `node --check audiobook.js`
- `CHROMIUM_EXECUTABLE=/path/to/chromium node tests/audiobook.cjs` (Playwright установлен отдельно; локальный тестовый сервер запускается самим тестом).

После утверждения потребуется публикация ветки и короткая проверка уже действующих адресов MP3/страниц. До утверждения эти адреса на основном сайте закономерно отсутствуют.

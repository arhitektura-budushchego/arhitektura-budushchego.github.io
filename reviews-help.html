Как управлять отзывами

Эта инструкция доступна без ChatGPT. Сохраните её адрес и адрес панели в закладках.

Вход

Откройте панель модератора. Введите почту и отдельный пароль модератора. После обновления или закрытия страницы потребуется войти снова.

Прочитать и опубликовать

Выберите «На модерации». Прочитайте текст и нажмите «Опубликовать». Он появится на странице отзывов после обновления страницы. Отзывы выводятся по 20, кнопки «Назад» и «Далее» переключают страницы.

Отклонить, снять, удалить

«Отклонить» скрывает отзыв, сохраняя его в панели. «Снять с публикации» возвращает его на модерацию. «Удалить» окончательно удаляет запись после подтверждения. Перед удалением сохраните резервную копию, если отзыв может понадобиться.

Выбрать до 10 отзывов для главной

У опубликованного отзыва выберите свободное место от 1 до 10 и нажмите «Сохранить место». Чтобы заменить отзыв, у прежнего выберите «Не показывать» и сохраните, затем назначьте освободившееся место новому. Если место занято, сначала освободите его. Снятие с главной не убирает отзыв из общего архива.

Резервная копия и перенос

Нажмите «Скачать резервную копию». Скачается JSON со всеми отзывами, датами, статусами и местами на главной. Делайте это после сеанса модерации и храните копии на двух устройствах. Платная подписка для скачивания не нужна. Этот открытый формат можно перенести в другую базу.

Восстановление владельцем: войдите в Supabase, откройте Table Editor → reader_reviews. Для небольшого числа отзывов добавьте записи через Insert row, сохраняя поля из JSON. Для массового восстановления преобразуйте массив reviews в CSV и используйте Import data; существующие id не должны дублироваться. Перед импортом сохраните текущую копию. Не импортируйте таблицу review_moderators из чужих файлов.

Если пароль потерян

Откройте Supabase → Authentication → Users, найдите свою запись модератора и используйте восстановление пароля, предложенное панелью. Если доступа к самой Supabase нет, восстановите вход на сайте Supabase через свою почту. Смена записи модератора требует назначения её user_id владельцем в таблице review_moderators через Table Editor. Не назначайте посторонних.

Лимиты и неполадки

Отзыв — до 1000 символов, имя — до 80. Файлы не принимаются. Защита ограничивает отправки с одного адреса: не чаще одного раза в минуту и до пяти в день. Общая защита — до 2000 отправок в день. Общее число сохранённых отзывов не ограничено числом записей; при размере всей базы от 450 МиБ приём останавливается до освобождения места.

Бесплатный проект Supabase может приостановиться после недели бездействия. Если сайт не загружает отзывы, откройте кабинет проекта и проверьте его состояние, при необходимости восстановите работу. Автоматические резервные копии бесплатного тарифа не включены. Проверяйте текущие условия на странице тарифов Supabase. Не переходите на платный тариф, если не хотите расходов.

Turnstile настраивается в вашем аккаунте Cloudflare. Его Secret Key хранится только в Secrets серверных функций Supabase под именем TURNSTILE_SECRET_KEY. При смене секрета обновите это значение. Site Key — публичный ключ формы.
